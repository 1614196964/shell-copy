# Shell Copy 1.1.0

## Updates

- Added automatic update checks, enabled by default, approximately once per day while the app runs.
- Added Check for Updates and an automatic-check toggle to the menu bar menu.
- Updates can be installed and the app relaunched after confirmation. Users can defer, skip a version, or cancel a download.
- Update feeds and archives are verified with Sparkle signatures. Failed checks do not interrupt clipboard processing.

## Download and installation

- Download ShellCopy-1.1.0.zip, extract it, and move Shell Copy.app into Applications.
- Requires macOS 13 or later. Includes both Apple Silicon and Intel executables.
- This release is ad-hoc signed, not signed with an Apple Developer ID and not notarized by Apple. macOS Gatekeeper may block the first launch. Only allow an individual app if you trust its source; do not disable system-wide security protections.
- Versions older than 1.1.0 must be replaced manually once. This version enables in-app discovery and installation of future releases; publishing it cannot notify older apps that lack an updater.
- The app runs in the menu bar, without a Dock icon or main window. Cloud modes require the user's own credentials and service access; no credentials are included.

## Publisher notes

- The ZIP is the installer download. appcast.xml is the signed update feed used by the app.
- Local integration tests cover automatic detection, deferral, cancellation, signature rejection, installation and relaunch, current-version checks, and unavailable feeds. Installation on another user's Mac may still encounter Gatekeeper restrictions.
